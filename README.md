**Discord Auth CLI** is an efficient command-line interface tool designed to streamline the Discord account authentication process. By interacting directly with the official Discord v9 API, this tool enables seamless token retrieval in a secure and developer-friendly environment.

## 🚀 Key Features
- **Secure Handling:** Utilizes `getpass` to ensure credentials remain protected and hidden during input.
- **Enhanced UI:** Delivers a superior visual experience with color-coded CLI feedback.
- **API Optimized:** Built for direct communication with Discord's authentication endpoints.
- **Clean Architecture:** Modular code structure designed for scalability and ease of integration.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Core Libraries:**
  - `requests`: Handles robust HTTP communication.
  - `colorama`: Enhances terminal output for better readability.
